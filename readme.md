# Sistema de Mesa de Partes

## Descripción
Prototipo desarrollado en Python para registrar y gestionar expedientes de una municipalidad.

## Funcionalidades
- Registrar expedientes.
- Buscar expedientes por código.
- Ordenar expedientes por código.
- Listar expedientes registrados.
- Generar constancias de recepción.
- Guardar los registros en un archivo CSV.

## Tecnologías utilizadas
- Python
- Git
- GitHub

## Archivos principales
- `mesa_de_partes.py`: contiene las funciones y el menú principal.
- `expedientes.csv`: almacena los expedientes registrados durante la ejecución.
- `EXP-0001.txt`: ejemplo del formato de archivo generado para una constancia.

## Ejecución
Ejecutar el archivo `mesa_de_partes.py` con Python 3.
